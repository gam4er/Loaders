# Loaders (Русский)

Loaders — это конвейер обфускации для .NET Framework 4.8: проект копируется в рабочую директорию, над ним выполняются этапы обфускации, затем он компилируется и запускается.

Основной процесс

- PrepareOutputProject: копирование исходного проекта в изолированную папку.
- LoadProject: парсинг csproj для получения списка файлов и ссылок.
- Обфускация строк: удаление комментариев и переписывание строковых литералов.
- Вставка перегрузок: добавление безвредных перегрузок методов для усложнения потока.
- Семантическое переименование классов: Roslyn-символы, безопасное обновление всех ссылок.
- Синтаксическая корректировка конструкторов: исправление вызовов, которые мог пропустить семантический этап.
- Семантическое переименование методов: Roslyn-символы, с фильтрами исключений.
- Компиляция: сборка и запуск обфусцированного бинарника в памяти.

Семантическое vs синтаксическое переименование

- Семантическое: работает с `ISymbol` Roslyn, аккуратно обновляет все использования (типовые ссылки, параметры, вызовы). Требует корректного набора `MetadataReference`.
- Синтаксическое: работает с синтаксическими деревьями, быстрее, но не понимает привязку символов, поэтому может пропустить или сломать код в краевых случаях.

Ключевые компоненты

- `InMemCompiler`: orchestration всех шагов.
- `ClassRenamer`: семантическое переименование классов.
- `MethodRenamer`: семантическое переименование методов по заранее отфильтрованным записям.
- `MethodCollectionRewriter`: сбор допустимых методов с учетом перегрузок.
- `SimpleConstructorRenameService`: точечный синтаксический проход для конструкторов.
- `StringLiteralObfuscationService` и переписчики: работа со строками и комментариями.
- `Loaders.GAC`: поиск ссылок на сборки в GAC.

Практики

- Сначала выполняйте семантическое переименование (классы/методы), затем синтаксические фиксы.
- Передавайте в Roslyn все корректные `MetadataReference` (из csproj + общие системные библиотеки).
- Централизуйте правила исключений (override, интерфейсы, extern/DllImport, `Dispose`, колбэки сериализации, `Main`, методы `object`) в фазе сбора.
- Храните структурированные записи (класс, метод, число параметров, новое имя) для избежания коллизий и правильной обработки перегрузок.
- Сохраняйте изменения на диск после успешного семантического обновления и сборки.

Сборка и запуск

- Восстановите legacy-проект `packages.config` и соберите его из Visual Studio Native Tools Command Prompt.
- Запускайте приложение с обязательными каталогами исходников и результата:

```text
Loaders.exe --source C:\path\to\source --output C:\path\to\output
```

- В каталоге исходников должен находиться ровно один файл `.csproj`.
- Каталоги исходников и результата должны быть раздельными; output пересоздаётся при каждом запуске.
- Для файловых этапов отображается процентный прогресс. Семантическое переименование Roslyn и компиляция показываются через live status.
- Для встроенной справки используйте `Loaders.exe --help`.
